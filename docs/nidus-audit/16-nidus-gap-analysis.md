# 16 - NIDUS Gap Analysis

## Target Product

NIDUS Academy OS aims to be an AI-powered defence academy operating system, not just ERP/LMS/CRM.

## Capability Gap Matrix

| Capability | Current evidence | Gap |
|---|---|---|
| CRM/admissions | Strong CRM and admission models/routes | Needs one guided journey and event transitions |
| LMS | Courses, learning hub, live/recorded classes | Needs one Learning Engine hierarchy |
| Defence academic planner | Academy planner/calendar/batch features | Needs single source of truth and normalized planner lifecycle |
| Question bank | Question, QuestionBankItem, assessment models | Needs one visible question-bank governance |
| Exams/mock tests | Tests, CBT, examination, assessment arena | Needs unified Examination Engine UX |
| AI | Multiple AI services/models | Needs invisible operating layer and governance |
| WhatsApp automation | Sales booster WhatsApp env/frontends | Needs platform-wide policy, opt-in, summaries |
| Finance | Payments/fees/invoices/Razorpay/manual | Strong, needs reporting and branch controls |
| HR | Faculty/payroll/admin users | Needs full HR lifecycle |
| Multi-branch | Branch/Institute models | Needs enforced tenant scoping |
| Parent portal | Parent dashboard/link models | Needs summarized communications and consent |
| Student portal | Student dashboards/learning/exams | Needs one daily learning journey |
| Teacher portal | Teacher dashboards/classes/assignments | Needs simpler class completion flow |
| Director command center | Director dashboard/reports | Needs exception-first executive intelligence |

## Biggest Gaps

1. Workflow/event orchestration.
2. Multi-branch authorization.
3. Unified academic source of truth.
4. Unified examination/question-bank surface.
5. AI governance and role integration.
6. Communication policy and WhatsApp cost control.
7. Test coverage for real journeys.

## Gap Verdict

The product foundation exists. The gap is not lack of features; it is coherence, governance, and operating-model integration.
