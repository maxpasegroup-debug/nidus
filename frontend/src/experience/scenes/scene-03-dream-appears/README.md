# Scene 3: The Dream Appears

## Purpose

Creates the first large emotional peak. The visitor should feel the private student dream expand into service, honour, and officer identity.

## Public API

- `DreamAppearsScene`

The scene expects `ExperienceShell` so it can use shared scene registration and scroll progress.

## Asset Placeholders

Uses `experienceSceneAssets.dreamAppears`. This is a centralized placeholder for final defence aspiration photography.

## Extension Points

- Replace the image from the media registry.
- Keep parallax restrained.
- Keep this scene CTA-free and transition-ready for the future purpose scene.
