# Scene 2: The Student Before The Dream

## Purpose

Creates recognition. The visitor should see the ordinary student before transformation and feel that the journey is personal.

## Public API

- `StudentBeforeDreamScene`

The scene expects to be rendered inside `ExperienceShell` for shared scroll progress and reduced-motion behavior.
