# NDIE Provider Integration Guide

Integrate providers through the orchestrator, not directly inside OCR, layout, formula, visual, question, evaluation, or validation services.

Provider integration steps:

1. Add provider metadata.
2. Implement the existing NDIE provider contract.
3. Register the provider in the existing provider registry.
4. Add routing capabilities.
5. Add benchmark expectations against the golden corpus.
6. Add cost and latency metadata.
7. Add health reporting.
