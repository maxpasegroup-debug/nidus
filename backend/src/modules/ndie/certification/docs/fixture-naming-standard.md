# Fixture Naming Standard

Use this format:

`<subject>-<exam>-<topic-or-risk>-<sequence>`

Examples:

- `mathematics-nda-3d-geometry-001`
- `physics-jee-circuits-001`
- `chemistry-neet-reactions-001`
- `gk-cds-history-001`

The folder name, manifest `documentId`, and repository entry `id` must match exactly.
