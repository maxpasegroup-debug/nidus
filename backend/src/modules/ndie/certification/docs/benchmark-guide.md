# NDIE Benchmark Guide

Benchmark runs must measure correctness and operating cost together.

Supported benchmark scales:

- 10 papers
- 25 papers
- 50 papers
- 100 papers
- 250 papers
- 500 papers
- 1000 papers

Stress cases:

- 100 simultaneous imports
- 500-page PDF
- 1000-page PDF
- 10000 questions
- 100 concurrent publishing jobs
- 10000 student render packages

Measure accuracy, duration, memory, worker usage, provider usage, confidence, throughput, and latency.
