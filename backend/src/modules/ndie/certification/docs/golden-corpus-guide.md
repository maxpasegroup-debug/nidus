# NDIE Golden Corpus Guide

The golden corpus is the permanent proof set for NDIE.

Each fixture must include:

- Original document path
- Expected OCR output
- Expected layout output
- Expected formula output
- Expected visual output
- Expected question output
- Expected answer and solution output
- Expected confidence targets

Required coverage:

- Simple text papers
- Multi-column papers
- Scanned and low-quality scans
- Rotated papers
- DOCX and Office Math
- Tables, graphs, diagrams
- Mathematics, Physics, Chemistry, Engineering Mathematics
- JEE, NEET, NDA, CDS, AFCAT, university papers
- Multiple answer-key and solution formats
- Legacy papers
