# Corpus Benchmark Standard

Benchmark scopes:

- Single document
- Single subject
- Single exam
- Full corpus

Every benchmark must report:

- Expected vs actual comparison
- Accuracy
- Confidence
- Processing time
- Provider
- PASS or FAIL

Thresholds:

- OCR accuracy greater than 98%
- Question detection greater than 99%
- Formula preservation greater than 98%
- Answer mapping greater than 99.9%
- Publish package 100%
- Student rendering 100%
